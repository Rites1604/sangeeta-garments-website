# Sangeeta Garments — Banarasi Heritage

A responsive, animated e-commerce front-end concept for Sangeeta Garments Manufacturing, showcasing Banarasi sarees and suits.

## Features
- Responsive desktop and mobile navigation
- Animated hero section with a 3D-style product card
- Collection category panels and product filtering
- Product detail modal
- Demo wishlist and shopping bag interactions
- Wholesale enquiries and WhatsApp call-to-action
- Scroll reveal effects and reduced-motion support

## Run locally
Open `index.html` in a modern browser. The web fonts and sample product images load from external URLs and require an internet connection.

## GitHub Pages
In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save. GitHub Pages will publish the site after its deployment completes.

## Before production
Replace sample photography, demo product names/prices, Instagram URL, and WhatsApp contact with business-approved information. The cart and wishlist are front-end demonstrations only; checkout, payments, stock management, and order fulfilment are not connected.
